Import a WhatsApp chat export

On your phone: WhatsApp → open the chat → ⋮ / contact name → Export Chat → Without media. Send the resulting _chat.txt to yourself, then drop it here. The contact's wa_id is derived from the phone number; the display name is auto-detected from the export.

Country code + number. Spaces, dashes, and "+" are fine. Will be auto-added to the whitelist.
Must match exactly how your name appears as the sender in the .txt file (case-sensitive).
If left blank, the most-frequent non-"me" sender in the file becomes the contact's name.
