Import a WhatsApp chat export

On your phone: WhatsApp → open the chat → ⋮ / contact name → Export Chat → Without media. Send the resulting _chat.txt to yourself, drop it here, and it'll be parsed and ingested. Run npm run process after to extract facts.

Edit config/whitelist.json to add contacts. Restart not required — the list reloads on each request.
Must match exactly how your name appears as the sender in the .txt file (case-sensitive).
